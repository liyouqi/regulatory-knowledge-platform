# 欧洲金融法规与国家落地法覆盖总计划

计划日期：2026-10-20。状态：**首批法规与国家目录已实施并完成本地验收；整体计划继续分阶段推进**。

本版替代此前“首轮7份”的有限扩展方案：建设范围为常用欧洲金融法规体系、欧盟27国国家落地法与监管材料，以及EEA非欧盟三国、英国、瑞士的独立国家覆盖。小批次用于控制实施与审阅成本，不再决定最终覆盖范围。

文件总数会随官方版本、合并情况和实际文件结构变化。修订文件、合并文本、同一法律不同语言与不同页面不能重复计算为新增业务覆盖。若一部国家法典覆盖多个领域，应保留一部法律身份并挂多个领域。

国家法下一批来源已推进：卢森堡 12 部核心法的精确身份、完整版本目录和 PDF 已冻结，其中 9 部另取得所选版本链接的 XML/HTML 及法文源 JSON。候选保真与版本身份尚未验证为可发布，覆盖数保持 121；下一包先处理 SIF/SICAR/RAIF，Sol High 仅批准 candidate-only 方案。法国三法典已定位 DILA 开放数据路线，尚未下载并组装法典。详见[2026-10-22 来源盘点](national-core-source-review-20261022.md)。

## 2. “欧洲常用”覆盖哪些领域

“常用”通过官方法规目录、监管规则书和机构常见合规工作来确定；首版以欧委会金融法规总览及EBA/ESMA/EIOPA规则书为发现入口。逐项做当前、未来适用、历史、被替代状态审阅，官方总览中的历史文件不自动按现行法接入。

| 基金与资管 | UCITS、AIFMD/AIFMD II、MMF、ELTIF、EuVECA、EuSEF、跨境分销；组织、委托、流动性、存管、杠杆、营销和报告 |
| 投资服务与市场行为 | MiFID II/MiFIR、MAR/MAD、Prospectus、BMR、Short Selling、Transparency、CRA、PRIIPs、Listing Act、众筹；投资者保护、适当性、产品治理、交易执行与披露 |

## 3. 国家覆盖：27国全部纳入，分组做深

| 国家组 | 国家 | 交付目标 |

| 第二组：其余17个欧盟成员国 | 保加利亚、克罗地亚、塞浦路斯、捷克、丹麦、爱沙尼亚、芬兰、希腊、匈牙利、拉脱维亚、立陶宛、马耳他、波兰、罗马尼亚、斯洛伐克、斯洛文尼亚、瑞典 | 同一12领域矩阵，先完整发现主干法律，再按国家接入正文与配套 |

三组的选择是项目实施优先级，不代表国家重要性或法律适用性排序。所有32国先完成来源登记与缺口清单，全文接入按组推进。英国、瑞士不会因被列入欧洲覆盖而被当作欧盟成员；EEA状态逐项核对。

每国跟踪12个领域：银行、基金、保险与养老金、支付、AML与制裁、投资与市场、恢复处置、消费信贷、可持续与企业报告、ICT与数据、监管规则、执法。国家法典跨领域复用，监管机构分工另作元数据。

## 4. 监管实践材料作为正式工作流

| 来源组 | 常用实践范围 | 交付策略 |
|---|---|---|
| EBA/ECB | 内部治理、适格性、SREP/ICAAP/ILAAP、贷款发放监测、信用风险、薪酬、第三方风险、报告披露 | 按业务家族建立文件清单，逐份审阅最终状态、正文边界及替代关系 |
| ESMA | 基金流动性、压力测试、营销与委托；MiFID适当性、产品治理、合规职能；MAR/Prospectus及报告解释 | 新来源能力先验收；Q&A、指引与法规正文保持各自身份 |
| EIOPA | 治理、ORSA、技术准备金、资本、报告、保险销售 | 治理/ORSA为首批，后续覆盖由Solvency II/IDD官方规则目录驱动 |
| AMLA/既有EBA AML材料 | 风险因素、合规官、CDD/EDD、开户、资金转移、制裁控制、集团政策 | 同时检查新旧主管机构与替代状态，保留正式发布及适用时间 |
| 国家监管机构 | 通函、规则书、监管条例、FAQ、报告说明、代表性执法决定 | 以国家×领域矩阵组织，包含CSSF/CAA、BaFin、ACPR/AMF、CBI、DNB/AFM等 |

Q&A正文扩展纳入建设范围，不再只以10至20条为最终目标：先清点所覆盖家族的官方Final/Published问答，按法律家族分批采集和验收；每条保留正式状态、日期、来源、引用及替代/历史信息。小批验收用样本，完整性按冻结的官方清单核对。全量目录与完整正文数始终分开。

## 5. 国家维度要让用户能做什么

1. 从国家入口进入某国金融监管地图，看到核心法律、监管机构、相关欧盟法规、已接入正文和缺口。
2. 在领域中选国家，或在国家中选银行/基金/AML等领域；搜索可按国家、语言、文件类型和版本过滤。
3. 从欧盟指令查各国已核实的转置措施，从欧盟条例查本地主管机构、执行/处罚和补充规则；官方通知候选与已核实链路分别展示。
4. 以同一主题比较不同国家的证据清单和已审阅差异；初期比较对象为材料与条文，不自动生成法律等价性结论。
5. 显示国家法律原文及其语言/法律地位。英语导航可以继续使用；无官方英文不阻止官方本国语言原文接入，翻译必须独立标识。

详细数据与工程顺序见[国家维度方案](financial-country-dimension-plan.md)。这是一条核心建设线，与欧盟增厚交替交付。

## 6. 实施阶段与里程碑

| 阶段 | 范围 | 阶段交付 |
|---|---|---|
| A：完整目录与技术准备 | 206个欧盟Work、32国×12领域；多国/语言/国家实施关系设计 | 逐项清点、官方版本发现、来源格式分组；国家能力合同经要求的高强度审阅后实施 |
| B：欧盟共同主干第一波 | 基金、保险/养老金、市场行为/产品、投资公司、可持续披露和剩余主干 | 每个领域都有核心法和关键配套；以完整领域清单收口，单批通常8至15份可复用结构文件 |
| C：国家能力与第一组三国 | 卢森堡＋法国＋德国，涵盖各自12领域清单 | 官方本国语言接入、国家页面/筛选、欧盟到国家链路与现有EU/LU回归；每国分多个法典/规则批次 |
| D：欧盟配套与监管实践 | B各家族的RTS/ITS/指引、ECB/ESA/AMLA材料、Q&A正文 | 主法—配套—监管解释可以追溯；大表格、公式、新来源单独解决 |
| E：第一组其余七国 | 爱尔兰、荷兰、意大利、西班牙、比利时、奥地利、葡萄牙 | 逐国12领域主要国家法与关键监管材料；按C可复用能力扩展 |
| F：其余17国 | 第二组全部成员国 | 先完成核心国家法律清单并逐国发布；监管实践随领域补齐，不以“有一份文件”算覆盖完成 |
| G：欧洲延伸与维护 | EEA非欧盟三国＋英国＋瑞士；欧洲范围持续维护 | 独立国家制度/EEA链路、版本更新、历史/未来状态、缺口复盘 |

阶段编号表示依赖和交付边界，不要求整个B结束才启动C。推荐顺序：A → B首批基金与市场 → C国家能力/卢法德 → B保险与可持续金融 → D/E → F/G。来源审阅和逐国清单发现可先推进，避免等待全部PDF解析能力。

EU Formex能复用时每批8至15份；大法典、表格密集附件或新PDF结构每批1至3份或一个可独立验收的来源格式。拆批为实施手段，整体清单持续推进。一个国家、一份综合法典或一个法规家族不得因拆成多批而重复计数。

### 工作量预算

当前明确的欧盟目录已达206个Work，国家部分至少有85个具名发现事项，并要扩展至全部384个国家×领域单元。规划容量按数百份正文与更多问答/关系记录安排；实际新增量在阶段A完成官方身份去重后给出，不用“国家数×固定文件数”伪造总量。

## 7. 完成口径与质量约束

- 每个欧盟家族与每个国家领域先固定具体范围、官方标识、关键配套和显式缺口；“发现了链接”“通知了措施”“完整正文可读”“关系已核实”分别计数。
- 新来源统一经官方身份/状态、快照校验、解析保真、Canonical质量、版本固定、Runtime及Profile验证；不降门槛绕过复杂材料。
- EU条例不标作被国家法转置。`IMPLEMENTS`沿用现有严格方向和精确证据；新增立法转置/EEA关系须先定义、审阅、测试，通知记录不直接塞入既有法律关系表。
- 本国语言原文与任何翻译、监管解释和编辑导航保持可区分；官方文本不可由LLM补写、翻译后冒充原文或静默纠错。
- 原始源、解析输出、Canonical、只读Runtime、UI分层；同一Node/TypeScript应用与构建准备流程继续复用。
- 各实施批次运行`npm run check`、`npm test`、`npm run build`和相应严格Profile构建；解析/关系/搜索变化运行专用fixture/eval；保留旧EU/LU ID、原文、检索与API兼容性回归。
- 每批交付可审阅报告、更新目录状态和国家矩阵；原始源、生成产物、秘密与本地环境文件不进入Git。原始快照保留与正式运行推广按既有流程执行。
- 业务覆盖验收以冻结范围内关键材料和证据路径为准；内部检索任务记录失败，用户价值仍待后续真实任务验证。
