# 法国 AMF 总规则正文接入审阅

启动日期：2026-10-21，验收完成：2026-10-22。状态：本地接入与发布门槛验证完成。承接 [候选解析与来源审计](fr-lu-candidates-20261021.md)及[发布合同方案](amf-20261021.md#contract-plan)。本轮目标为本地 Canonical → Reader → Runtime → API/MCP → 检索/精确引用 → RAG 的完整接入；最终验收结果见下文。

## 来源与覆盖边界

新增一份法国法语规则书 `fr:amf:rg`，Reader slug `amf-rg`。保存 693 个分组、1,821 条文和 132 个发布者信息框：文档 1、分组 63、条文 68。国家页面按一份本国材料计数。基金、投资市场和监管规则领域标为部分正文覆盖；法国货币金融法典等核心法律仍在后续清单。本轮不创建法国转置或 `IMPLEMENTS` 关系，也不宣称法语跨语种语义检索已评估。

冻结源为 [AMF 官方入口](https://www.amf-france.org/fr/eli/fr/aai/amf/rg)的既有官方抓取，2,475,701 bytes，SHA-256 `77779fb29c2f9fffdcc5951f155f1393265a895b480a0f68f98329884c231fb4`；原始 probe 报告独立冻结。独立 HTMLParser 与候选 AST 对照了全部标题、URL、祖先、正文与信息框哈希、归属和位置。正式解析器还逐框对照锁定 baseline。

源版本标签为 [2026-09-11 版本](https://www.amf-france.org/fr/eli/fr/aai/amf/rg/20260911/notes)。本轮重试入口与版本链接均返回 HTTP 200 维护页，无条文；这些响应被拒绝，没有替换既有完整源，也不作为当前版本认证。

## 日期与来源地位

- `publicationDate=null`，原因为 `aggregate-with-multiple-component-publications`。Book I 的初始公报日期为 [2004-10-29](https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000254713)，Books II–VI 为 [2004-11-24](https://www.legifrance.gouv.fr/jorf/jo/2004/11/24/0273)。这些分卷证据不能转换成整份集合的一个公布日。
- `textAsOf=2026-09-11` 是发布者版本日期；`textAsOfBasis=publisher-version-date`、`textAuthorityStatus=publisher-consolidation`、`currencyStatus=not_assessed`。生效、适用、废止状态均未推断。
- 归档目录只支持 `capturedOn=2026-10-20`，依据为 `archived-probe-directory`；精确 `retrievedAt=null`，依据为 `date-only-official-probe`。`importedAt=2026-10-21T18:21:48.225Z` 是实际导入时间。Reader 的 `lastChecked` 是独立来源审阅时间。

## 合同与渲染

新增 Canonical 1.5、AMF HTML parser 1.0.1、Runtime 5.12、Public API 1.5、RAG Snapshot 1.3。EU/LU Canonical 1.2、DE 1.3/1.4 的字段验证分支继续冻结；RAG 1.1/1.2 继续独立验证。1.0.0 的本轮未发布草稿产物保留，1.0.1 不覆写旧文件。

条文及分组 ID 来自完整官方 URL 的 SHA-256，只表示源地址身份，不声称跨版本连续性。`212-19` 与 NBSP `212-19 bis` 保留不同 ID、路由及完整 URL，即使正文和部分路径编号相同也不合并。所有分组和条文共用连续的源遍历顺序，祖先链、XPath 和 owner 均校验。

64 个文档/分组信息框单独保存 owner、官方 URL、原位置、locator、规范化块和内容哈希。Reader 在所属文档/祖先上下文显示；不生成可引用法律实体、不进入正文检索或关系端点。68 个条文信息框在原位置以 source-note 角色保存。源文不改写，法文 inline run 按原序直接拼接；链接、上标、斜体和有序/无序列表通过规范化 layout 渲染，UI 不解析原始标签。

FR API 文档必须显式返回空公布日及依据，其他法域保留可选非空日期；Zod/OpenAPI/MCP 使用同一版本边界。RAG 导出准确区分版本日、公布日和抓取/导入时间，并核对全部信息框哈希、归属和顺序。

默认本地 Runtime 使用既有 Canonical 目录，完整 strict Runtime 使用 manifest 固定源重建，二者 build ID 分别为 `runtime-5.12.0-a6a7244f54fca0b1` 与 `runtime-5.12.0-cd1be29c2d454740`。逐份深层对照的差异仅涉及33份旧文档的 `lastChecked`，其中3份还涉及Reader正文和结构相同的不同源包之 snapshot/version/build 标识；所有文档正文、结构和AMF数据一致，详见 `strict-reader-differences.json`。它们是两个独立产物，不能混称同一个构建。

第二轮 `full-test-clean.log` 的117个文件、546项断言全部通过，但仍有两项未处理RPC错误，exit 1，仍不计完整通过。仅在 `beforeAll` 末尾单次 `setImmediate` 不足以解决。

## Contract plan

以下为实施前通过审阅的合同约定；实际版本和验收结果以上文为准。

实施前方案与实施复审均已通过 Sol High；最终验证见 [AMF 发布审阅](amf-20261021.md)。本方案延续[法卢候选记录](fr-lu-candidates-20261021.md)的冻结输入：SHA `77779fb29c2f9fffdcc5951f155f1393265a895b480a0f68f98329884c231fb4`，AST SHA `9d5255c0b2aac12985b60b9c80a7f9ea075f91353a588592c96d126f92976fcb`，693 分组、1,821 条文、132 信息框（文档 1 / 分组 63 / 条文 68）。

### 日期与来源

- Book I 的初始公报日期为 2004-10-29：[官方批准令](https://www.legifrance.gouv.fr/jorf/id/JORFTEXT000000254713)。Books II–VI 为 2004-11-24：[官方公报](https://www.legifrance.gouv.fr/jorf/jo/2004/11/24/0273)。整份合并集合的 `publicationDate` 显式为 `null`，两个来源日期另作分卷证据；不猜测一个总公布日。
- `textAsOf=2026-09-11` 仅表示发布者版本标签；新增 `textAsOfBasis=publisher-version-date`、`textAuthorityStatus=publisher-consolidation`。`currencyStatus=not_assessed`，不据此判断生效、废止或最新性。
- 本轮尝试官方入口和版本链接，均 HTTP 200 但内容为 24,489 bytes 的维护页（无条文），必须拒绝。证据位于 ignored 的 `data/raw/amf-probes/20261021T150356Z/` 与 `20261021T150504Z/`。
- 导入既有官方 probe：完整 HTML 与原始 `report.json` 分开冻结，核验原报告对应 URL、HTTP 200、字节数和 SHA；日期 `capturedOn=2026-10-20`，精确 `retrievedAt=null`，`importedAt` 记录实际导入时间，明确 `retrievalTimestampBasis=date-only-official-probe`，不能把导入时间冒充获取时间。维护页不能替换此源。

### Canonical 1.5

- 冻结旧 1.2 / 1.3 / 1.4 分支、旧 content-unit 和 source-status 验证行为。新增严格 FR / fr / regulation / amf 分支，Document ID `fr:amf:rg`，localId `fr-amf-rg`。
- Article ID 为 `fr:amf:rg:article:<sha256(完整官方URL)>`；分组使用 `fr:amf:rg:structure:<sha256(完整分组URL)>`。保留完整原始标题、原 href、URL 与 XPath；这些是来源地址身份，不声称已证明跨历史版本连续性。`212-19` 和 NBSP `212-19 bis` 分别保留，不从路径编号或相同正文推导合并。
- 每条文仍只有一个可引用源单位；不生成段落/列表点的稳定法律 ID。68 个条文信息框在 `orderedUnits` 内原位置、独立 source-note 角色保留。
- 新增规范化 `link/href`、`superscript`、`list/listStyle=ordered|unordered`，保留内联斜体、Unicode 和源顺序。旧 unit 分支拒绝新字段，UI 只读规范化 layout，不解释 sourceName/sourceAttributes。
- 新增 `scopedSourceNotes[]`（64 条文档或分组信息框）：`ownerId, ownerSourceUrl, position, sourceLocator, orderedUnits, contentHash`，全部 source-note。验证 owner 存在、URL/哈希身份、位置、顺序及文本哈希；它们不是 provisions 或法律关系端点。

### Reader / Runtime / API

- DocumentView 新增可选 `publicationDate`，FR 必须为 null；其 `asOf` 使用明确标示的发布者版本日期。旧文档的字段和 `asOf` 行为保持可比。
- FR 的 `lastChecked` 使用 sourceStatus 的必需 `checkedAt`（来源审阅时间），不伪装为 source.retrievedAt。
- DocumentView 保留 693 个分组（包括空分组）与全部 scopedSourceNotes。信息框投影为带 owner 标签、位置和 source-note BodyBlock 的独立元数据。单条文 Reader 以明确所属文档/祖先分组的上下文显示，不把信息框归作条文正文；条文内 68 框仍在正文前原位置显示。
- 搜索、精确引用、法律实体和关系构建不纳入 scopedSourceNotes。所有源文本及角色哈希按冻结候选逐项独立核对。
- Runtime 5.12：documents.publication_date 对 FR 允许 null；新增 as_of_date 保留 DocumentView.asOf。旧 publication_date 值不改。语言约束增 fr，公共法域增 FR；banking-default 仍为 99 且不混入 FR。
- Public API 1.5：同步 FR/fr、FR 显式为空、其他法域可选非空的 publicationDate 和规范化内容字段，OpenAPI/MCP/服务合同一致。

### RAG 1.3 / 构建

- 冻结并继续验证 1.1 与 1.2。1.3 的 FR `date_document` 与 `retrieved_at` 显式 null，版本日期和 importedAt/捕获日期另记；旧文档的日期仍不可空。
- 64 条 scopedSourceNotes 在 document 的 `scoped_source_notes` 导出，包含 scope/ownerId/ownerSourceUrl/ownerLabel/position、精确文本及 locator。验证 owner URL 哈希与文档/分组归属，不能视为可引用法律实体；68 条 article note 复用 provision.source_notes。
- 原始 inline run 拼接策略：fr/de 为原序直接拼接；旧 English 策略不变。法域、语言、source-status、日期未知原因在导出及 verifier 中严格对应。
- 独立 AMF registry / snapshot / CLI / parser，不扩德国 GII 入口。原源字节、probe 证据、候选 AST 与完整 baseline 质量哈希均锁定；active 必须有已审阅质量基线。
- Manifest 新增显式 amf adapter，strict build 与 release 验证加入 AMF 来源；既有 exact coverage、checksum、archive 和质量条件不放松。目标 full-corpus 121，banking-default 99；不创建转置、IMPLEMENTS 或根据说明框链接推断的关系。
